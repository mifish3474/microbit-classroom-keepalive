# Substitute teacher: access and recovery

**Try a fresh join before students arrive. The extension badge does not guarantee access.**

The teacher should leave the official saved classroom HTML recovery file in a school-approved location, plus the lesson and where joining details are normally shared. Do not attach exports containing pupil data to public tickets or send them outside approved channels.

1. Keep the teacher dashboard and **Classroom Monitor** windows open, workstation plugged in, and approved network connected.
2. Try the existing joining details from another device or fresh browser context. If successful, use them for class. In the extension popup, check the confirmation box and click **Record my join check**. Version 0.1.2 clears the **?** reminder and keeps the verification time; this does not guarantee future access.
3. If joining fails, check the teacher dashboard for expired/ended/offline warnings. Restore normal connectivity if appropriate. Do not bypass school security or sign-in prompts.
4. Click **Stop** in the extension. Open the teacher's official saved classroom HTML file in Chrome.
5. Click **Continue classroom session** and follow the app's prompts. The teacher must rehearse this exact recovery before handoff; live recovery has not been validated by the prototype.
6. Read the resulting dashboard's joining details. **They may be new: do not assume the old link or PIN still works.** Share the current details through the approved school channel.
7. Test a fresh join before inviting students. If desired, manually rejoin the monitor as **Classroom Monitor** and explicitly Start the extension on its student tab.

If official recovery fails, contact the designated school support person and use the lesson's approved fallback. Creating a new classroom and sharing a new link are manual teacher decisions; the extension never performs them.

A moving block proves local editor activity only. A red **!** needs attention; **?** is a reminder to test a fresh join. A blank badge after recording a join means the reminder was acknowledged, not that future access is guaranteed.
